# Demo walkthrough

## Creator path

1. Open `/token/create`.
2. Review the route-selection page and requirement groups.
3. Confirm each statutory/classification/external action control shows a green citation chip.
4. Expand any citation drawer to see requirement ID, bill/section label, local source file, source line range, and excerpt.
5. Review the hosted form links:
   - `/forms/demo/offering-statement`
   - `/forms/demo/purchaser-information`
   - `/reports/0xDemo/semiannual/2026-H1`
   - `/certifications/0xDemo/maturity`
6. Open `/launch/mechanics` and verify every launch/deploy field is labeled: `Smart-contract launch requirement — not a CLARITY Act requirement`.

## Buyer path

1. Open `/token/0xDemo`.
2. Review the buyer-visible completed public forms and reports before any purchase decision.
3. Verify the token page links the offering statement, purchaser information, semiannual report, and maturity certification package.
4. Verify the confidential ownership section says only: `Confidential ownership list completed; not public by default.`
5. Confirm no confidential sample person name or wallet value appears on public pages.

## What is intentionally fake

- No real token deployment.
- No private key, API key, or Bankr/Liquid/Doppler API call.
- No SEC/Commission filing.
- No production audit claim.
- No onchain transaction or mainnet address.
